# 🍕 Landing Page - Pizzaria (Versão 1)

Landing page responsiva para uma pizzaria. Projeto focado na construção de interface de utilizador (UI) utilizando marcação semântica em HTML5 e estilização visual com CSS3.

O objetivo desta aplicação foi aplicar conceitos práticos de estruturação web, desenvolvendo um layout atrativo e focado na apresentação de produtos de forma clara e comercial.

## 🛠️ Tecnologias e Conceitos

* **HTML5:** Criação do esqueleto da página e marcação dos elementos textuais e de imagem.
* **CSS3:** Aplicação de cores, tipografia, margens e estruturação do design da interface.
* **UI/UX Básica:** Foco na experiência de navegação do utilizador final.
